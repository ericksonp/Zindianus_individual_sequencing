This repository contains code for analyzing *Zaprionus indianus* individual sequencing data published by Erickson et al.

# 0.Figures_revised
Contains code to generate all data figures in the main text and supplement

# 1.Mapping
contains scripts to map raw sequencing reads, call SNPs, filter, and generate final vcf

# 2.snpEff
Contains scripts to run snpEff to determine functional variants

# 3.Smoove_structural_variants
Contains scripts to call structural variants with Smoove software

# 4.Inversions_LD
Contains scripts to identify long distance LD between SNPs to test for Inversions_LD

# 5.Populuation structure
Contains scripts for PCA and ADMIXTURE analysis

# 6.Demographic_history
Contains scripts for ancestral population size reconstruction in smc++ plus analysis of relatedness and inbreeding

# 7.Treemix_DAPC
Contains scripts to analyze North American data using Treemix and Treemix_DAPC for analysis of recolonization potential

# 8.Selection
Contains scripts for FST, Baypass (XtX) and IHS tests as well as window-based scan to combine results, and an analysis of some of the haplotypes of interest

# 9.Descriptives
Contains scripts to analyze window-based population genetic signals genome wide (Fst, Dxy, Pi, Tajima's D, sequencing depth)
